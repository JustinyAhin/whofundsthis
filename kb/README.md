# Who Funds This? knowledge base

Who Funds This? helps researchers discover who has funded work like theirs, especially in their country or region, using historical award data from OpenAlex.

## Start here

1. [Project brief](project.md) — problem, positioning, users, and business hypothesis.
2. [MVP](mvp.md) — the first useful product loop and its boundaries.
3. [SEO](seo.md) — the initial acquisition opportunity and publishing rules.

Keep this folder lean. Add a document only when a durable decision no longer fits one of these three files.

Research was gathered on 2026-08-25. API capabilities, competitors, domains, and search demand can change.
